基本レイアウト

本文・一覧・比較。全体の八割はこの三つで足りる。

見出しと本文の基本形

情報の階層は、書体の大きさと余白だけで示す。囲み枠や色地は使わない。

A
一枚に主張はひとつ
補足は話し手が言う。スライドは論点の見出しに徹する。
B
強調は書体の太さで足りる
下線・蛍光マーカー・色替えを重ねない。効かせる箇所は一枚に一つ。
C
下端の余白は詰めない
空きは余りではなく、視線の落ち着き先として確保しておく。

Markdown と HTML の役割分担

MARKDOWN
書くのが速い。差分が読める。
構成を考える段階では、これ以上の道具がない。
ただし表現力は記法の範囲で止まる。
HTML
一枚ごとに寸法を決められる。
図・表・グラフに抽象の壁がない。
手で書くと重いが、そこは生成に任せる。

色と図表

Marp で一番苦しかった領域を、素の HTML で組み直す。

色の役割

色ごとに役割をひとつだけ決める。迷ったら使わない、が既定。

地と文字
base / text
この二値が全体の基調。反転面は #4c4f69 のみで、他の暗色は作らない。
罫線
#8c8fa1 / #bcc0cc
枠罫（見出し下・フッター上・表の外側）に #8c8fa1、内部の行間に #bcc0cc。この二段だけ。
主張
maroon #e64553
一枚に一箇所まで。ここを見せたいという合図。増やすと効かなくなる。
構造
teal #10797a
番号・記号・ラベル（カラム名や分類名）。見出しの階層とは別系統で、同じ役割の要素すべてに等しく載せる。
図表
series 1–6
系列を区別するためだけの色。本文や装飾には持ち出さない。

PRESENTATION TEMPLATE 13

一枚の書き方

スライドは section 一つ。属性で見出しと読み上げ原稿を持たせる。

記法を覚える代わりに、寸法をそのまま書く。ここが Marp との一番の違い。

<section data-label="標準"
data-speaker-notes="..."
style="padding:96px 120px 84px">
<h2>見出し</h2>
<div style="height:1px;background:#8c8fa1"></div>
<p>本文</p>
</section>

03

文字要素の作法

見出し・リスト・表・数式・カード。毎回迷う五つを先に決めておく。

見出しの階層

定義
h1
112px / 700
表紙と章題だけ。本文スライドには置かない
h2
68px / 700
一枚の主題。直下に 1px の罫線を必ず引く
h3
42px / 500
枚内の区切り。罫線は付けない
ラベル
26px / 字間 0.14em / teal
階層の外。h4 ではなく、色の役割「構造」の一種としてカラム名・分類名を示す

h1–h3 が序列、ラベルはその外側で名前を示すだけ。

実例

階層は三段で足りる

段を増やすと、読み手は上下関係の推測に時間を使う。段の数ではなく余白の差で示す。

補足

この「実例」「補足」がラベル。h3 より小さいが下位ではない。太字にせず、teal と字間だけで区別する。

PRESENTATION TEMPLATE 18

リストと番号付きリスト

箇条書き
  • 順序に意味がないときは箇条書き
  • 一項目は一行。折り返すなら文を切る
  • 階層は二段まで
    • 第二階層は横罫、色を落とす
    • 三段目が出たら図か表に替える
番号付き
  1. 01 手順・優先度があるときだけ番号を振る
  2. 02 二桁ぞろえ。桁で頭が揃う
  3. 03 項目間は罫線で区切り、記号は足さない
  4. 04 五項目を超えたら図解か表に移す

行間は 1.55–1.6。項目間の空きは行間より広く取る。

PRESENTATION TEMPLATE 21

数式

文中の記号は本文の流れに置く。事後確率 p(θ | D) は、尤度と事前分布の積に比例する。

p(θ|D) = p(D|θ)p(θ) / ∫p(D|θ)p(θ)dθ
(1)
θ推定したい母数
D観測されたデータ
p(θ)事前分布
KaTeX を CDN で読む。式は data-tex 属性に書く
独立式は一枚に一つ。番号は参照するときだけ
記号の説明は式の下。本文中で言い換えない
PRESENTATION TEMPLATE 22

カードの三型

TYPE A
罫線カード
既定の型。図解の箱と同じ 1px の枠。三つか四つ並べる。
枠を持つ最小単位
TYPE B
上罫のみ
枠で囲まず、頭の罫線だけで区切る。文章量が多いときの既定。
五つ以上の並列に
TYPE C
反転カード
墨地で一つだけ持ち上げる。結論・現在地・到達点に使う。
一枚に一つまで
中身の順序 ラベル（teal・24px）→ 見出し（36px / 500）→ 本文（27px）→ 下端に補足。四段目は置かない。
寸法 内側は 40px / 36px、列間は 56px。高さは grid で揃え、内容で伸ばさない。
禁止 角丸・影・色地・左端のアクセント線。カードは枠であって装飾ではない。
PRESENTATION TEMPLATE 23

運用の三原則

一
レイアウトは増やさない。足りなければ内容を削る。
二
差し色は二色。主張に maroon、構造に teal と決めて使う。
三
寸法は直接書く。抽象を挟むのは繰り返しが出てから。
