## 図表の系列色

図・グラフ・ブランチ図の系列に使う。**左から順に使い、飛ばさない。**

| # | 値 | Latte 名 | 含み |
|---|---|---|---|
| 系列 1 | `#1e66f5` | blue | 基準・幹 |
| 系列 2 | `#10797a` | teal | 対になるもう一方 |
| 系列 3 | `#8839ef` | mauve | 枝分かれ・派生 |
| 系列 4 | `#40a02b` | green | 完了・正常 |
| 系列 5 | `#df8e1d` | yellow | 保留・待機 |
| 系列 6 | `#ea76cb` | pink | 例外・特殊 |

**maroon `#e64553` は系列に入れない。** 異常系・障害・注意にだけ残す。系列が 7 つ必要になったら、色を足すのではなく図を分ける。

系列色は図の中だけで使う。本文の強調や見出しには持ち出さない。

差し色は二色。**役割で使い分け、混ぜない。**

- **maroon `#e64553`** — 主張と異常系。用途は二つだけ。(1) 本文で一番言いたい語句を `strong` で赤く（一枚に一箇所）、(2) 図のなかの失敗・停止・注意を示す経路と節点。それ以外には使わない。
- **teal `#10797a`** — 構造。目次番号、項目記号（A/B/C）、カラム見出し、図解のステップ番号と接続点。暗地の上では淡い teal `#94e2d5`。

構造色は同じ役割の要素すべてに等しく載せる。主張色は逆に、一枚のなかで一箇所だけに絞る。

## 書体

- 全体: `'M PLUS Rounded 1c', sans-serif`（400 / 500 / 700）
- コードのみ: `'JetBrains Mono', monospace`

## 文字要素

| 要素 | 決めごと |
|---|---|
| 見出し | h1 112/700（表紙・章扉のみ）、h2 68/700 ＋直下に 1px の枠罫、h3 42/500（罫線なし）。四段目は作らない |
| ラベル | 26px・字間 0.14em・teal `#10797a`。見出しの階層に入らない別系統で、カラム名や分類名を示す。太字にしない |
| 箇条書き | 記号は teal の 11px 正方形。第二階層は 16px の横罫 `#8c8fa1` ＋文字を `#5c5f77` に落とす。二階層まで、5 項目まで |
| 番号付き | teal の二桁ぞろえ（`01`）＋ `font-variant-numeric:tabular-nums`。行間は 1px の内部罫、記号は足さない |
| インデント | `padding-left` ではなく grid の列で作る（記号列＋本文列）。刻みは 48px、二段まで。段落頭の字下げはしない。引用・コード・表・図は版面幅のまま下げない |
| 固定列幅 | 番号列 78px、ラベル列 96px（標準レイアウトの記号列 96px も同じ）。ほかの列幅は作らない |
| 表 | 横罫のみ。ヘッダは 24px・字間 0.16em・`#6c6f85`。外側は枠罫、行間は内部罫。文字列は左、数値は右で `tabular-nums`、単位は見出しへ出す。5 行 4 列まで、maroon は差分 1 列だけ |
| 数式 | KaTeX を CDN で読み、`data-tex` 属性に式を書く（独立式は `data-tex-display`）。独立式は上下の枠罫で挟み、`padding:36px 0`・46px・右端に teal の式番号。記号の説明は式の下に横並び。一枚に一つ |
| カード | 三型のみ。A 罫線カード（1px `#4c4f69`、内側 40px/36px、既定）、B 上罫のみ（3px の上罫、5 つ以上の並列に）、C 反転カード（`#4c4f69` 地、一枚に一つ）。中身はラベル→見出し 36/500→本文 27px→下端の補足の四段。列間 56px、高さは grid で揃える。角丸・影・色地・左端のアクセント線は禁止 |

## 余白

- 通常スライド: `padding:96px 120px 84px`
- 表紙・章扉: `padding:120px`
- 引用: `padding:120px 160px`
- 見出し下の罫線までの空き: 20px、罫線から本文まで 36〜72px
- カラム間: 72〜96px
- 行の並びの上下 padding: 14〜28px（項目数が多いほど詰める）

**合計が 1080px を超えないこと。** 超えたら余白を詰め、詰めきれなければ内容を削る。文字を 24px 未満にはしない。
