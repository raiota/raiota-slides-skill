## 図表の系列色

図・グラフ・ブランチ図の系列に使う。**左から順に使い、飛ばさない。**

| # | 値 | Latte 名 | 含み |
|---|---|---|---|
| 系列 1 | `#1e66f5` | blue | 基準・幹 |
| 系列 2 | `#10797a` | teal | 対になるもう一方 |
| 系列 3 | `#8839ef` | mauve | 枝分かれ・派生 |
| 系列 4 | `#40a02b` | green | 完了・正常 |
| 系列 5 | `#df8e1d` | yellow | 保留・待機 |
| 系列 6 | `#ea76cb` | pink | 例外・特殊 |

**maroon `#e64553` は系列に入れない。** 異常系・障害・注意にだけ残す。系列が 7 つ必要になったら、色を足すのではなく図を分ける。

系列色は図の中だけで使う。本文の強調や見出しには持ち出さない。

差し色は二色。**役割で使い分け、混ぜない。**

- **maroon `#e64553`** — 主張と異常系。用途は二つだけ。(1) 本文で一番言いたい語句を `strong` で赤く（一枚に一箇所）、(2) 図のなかの失敗・停止・注意を示す経路と節点。それ以外には使わない。
- **teal `#10797a`** — 構造。目次番号、項目記号（A/B/C）、カラム見出し、図解のステップ番号と接続点。暗地の上では淡い teal `#94e2d5`。

構造色は同じ役割の要素すべてに等しく載せる。主張色は逆に、一枚のなかで一箇所だけに絞る。

## 反転面（`#4c4f69` の地）の使いどき

反転は色ではなく**句読点**として扱う。地色を反転させるのは、次の三つの場合だけ。

| 使う | 理由 |
|---|---|
| 章扉のスライド全面 | 話題が切り替わることを、内容を読まずに知らせる |
| 並びの終端（図解の最終段） | 流れの着地点を示す。読み手の目はここで止まる |
| コードパネル・引用の地 | 本文とは別の種類のテキストであることを示す |

- **一枚に一つ。** 反転面が二つ以上あると、どちらが終端か分からなくなる。
- **並びの途中には置かない。** 強調したい段が中間にあるなら、反転ではなく maroon の語句強調を使う。
- 反転面の上では、見出し `#eff1f5`・本文 `#ccd0da`・構造色は淡い teal `#94e2d5` に差し替える。枠線は付けない（地の面積で十分に立つ）。
- 反転面の番号だけは **maroon 淡 `#f2cdcd` の塗り円＋`#4c4f69` の数字**にする。終端であることを一点で示すため。maroon `#e64553` は暗地の上で 2.2:1 しか出ないので、暗地では必ず淡い側を使う。塗り円は一枚に一つまで。
- 反転を「重要だから目立たせる」目的で使わない。重要さは maroon、位置は反転。役割が混ざると両方効かなくなる。

## 文字要素

| 要素 | 決めごと |
|---|---|
| 見出し | h1 112/700（表紙・章扉のみ）、h2 68/700 ＋直下に 1px の枠罫、h3 42/500（罫線なし）。四段目は作らない |
| ラベル | 26px・字間 0.14em・teal `#10797a`。見出しの階層に入らない別系統で、カラム名や分類名を示す。太字にしない |
| 箇条書き | 記号は teal の 11px 正方形。第二階層は 16px の横罫 `#8c8fa1` ＋文字を `#5c5f77` に落とす。二階層まで、5 項目まで |
| 番号付き | teal の二桁ぞろえ（`01`）＋ `font-variant-numeric:tabular-nums`。行間は 1px の内部罫、記号は足さない |
| インデント | `padding-left` ではなく grid の列で作る（記号列＋本文列）。刻みは 48px、二段まで。段落頭の字下げはしない。引用・コード・表・図は版面幅のまま下げない |
| 固定列幅 | 番号列 78px、ラベル列 96px。ほかの列幅は作らない |
| 表 | 横罫のみ。ヘッダは 24px・字間 0.16em・`#6c6f85`。外側は枠罫、行間は内部罫。文字列は左、数値は右で `tabular-nums`、単位は見出しへ出す。5 行 4 列まで、maroon は差分 1 列だけ |
| 数式 | KaTeX を CDN で読み、`data-tex` 属性に式を書く（独立式は `data-tex-display`）。独立式は上下の枠罫で挟み、`padding:36px 0`・46px・右端に teal の式番号。記号の説明は式の下に横並び。一枚に一つ |
| 二段組 | 中央に 1px の内部罫 `#bcc0cc` を一本。列間は 72〜96px、左右の行数を揃える。三段組は作らない |
| コードパネル | `#4c4f69` の地に角丸 32px、`padding:44px 48px`、等幅 24px・行間 1.8。枠線・影は付けない。インラインコードは角丸 8px の薄い墨地 |
| 図解の箱 | 角丸 32px・2px `#4c4f69` の枠。番号は 52px の円（2px `#10797a`）。最終段だけ `#4c4f69` の地に反転し、番号を `#f2cdcd` の塗り円にする。影は付けない |
| 棒グラフ | 棒は teal、上端だけ角丸 12px。注目の一本を maroon に。目盛り線は引かず、基線 1px `#8c8fa1` と棒上の数値で読ませる。棒の最大幅 150px、列間 56px |
| 線グラフ | 系列は二本まで（teal / maroon）。線は 4px・丸端、頂点は地色で抜いた r=9 の丸。横の目盛り線は `#bcc0cc`、基線だけ `#8c8fa1`。凡例は図の上 |
| 図解の接続 | 3px `#8c8fa1` の横線＋12px の teal 丸。矢印の頭は描かない |
| 説明＋図版・コードの二段組 | 左 1fr : 右 1.5fr、列間 80px。行は見出し罫とフッター罫のあいだを埋め、左右とも `align-items:center` で垂直中央に揃える（上寄せにすると右の塊が浮く）。図版枠は高さ上限 520px |
| 写真・図版枠 | 1px `#4c4f69` の枠を親 `div` に引き、中身は `<image-slot>`（`assets/image-slot.js` を読む）。顔写真は 420×420・`fit="cover"`、図版は `fit="contain"`。角丸にしない |

## 余白

- 通常スライド: `padding:96px 120px 84px`
- 表紙・章扉: `padding:120px`
- 引用: `padding:120px 160px`
- 見出し下の罫線までの空き: 20px、罫線から本文まで 36〜72px
- カラム間: 72〜96px
- 行の並びの上下 padding: 14〜28px（項目数が多いほど詰める）

**合計が 1080px を超えないこと。** 超えたら余白を詰め、詰めきれなければ内容を削る。文字を 24px 未満にはしない。
