# スライドテンプレート

ピッチ・ライトニングトーク・報告資料のための 1920×1080 の HTML スライドを組む。出力は `deck-stage.js` を読み込んだ単一の HTML ファイル。

## 手順

1. **構成を先に決める** — 見出しだけを箇条書きで並べ、ユーザーに確認を取る。いきなり HTML を書かない。
2. `assets/boilerplate.html` を出力先にコピーし、`assets/deck-stage.js` を隣に置く。数式を使わないなら KaTeX の 2 行と typeset 関数を消す。
3. 各スライドについて、`assets/layouts.html` から**該当レイアウトの `<section>` をそのまま貼り**、中の文字だけ差し替える。
4. `reference/tokens.md` の値から外れないこと。新しい色・サイズ・罫線の濃さを作らない。

画像は `assets/image-slot.js` を読み込み、`<image-slot id="…" placeholder="…">` を枠の中に置く（ユーザーが後からドロップする）。`deck-stage.js` と並べて読む。

## レイアウト一覧（`assets/layouts.html`）

| # | `data-label` | 用途 |
|---|---|---|
| 01 | 表紙 | タイトル・サブタイトル・日付 |
| 02 | 自己紹介 | 写真枠＋名前・肩書き・職務経歴 3 行 |
| 03 | 目次 | 番号付きの項目。5 つまで |
| 04 | 章扉 | 話題の切り替え。暗地＋巨大な番号 |
| 05 | 見出しと本文 | h2 / h3 / 本文の基本形 |
| 06 | リスト | 箇条書き（teal 正方形・二階層）と番号付き（左端の縦線） |
| 07 | 表組み | 数値を含む表。右揃え＋増減 |
| 08 | 数式 | KaTeX の独立式＋記号の説明 |
| 09 | 図解 | 角丸の箱と接続線。4 ステップのプロセス |
| 10 | 図表・SVG | 線でつながる図。系列色の実例 |
| 11 | 棒グラフ | `div` の `height` だけで作る縦棒。注目の一本だけ maroon |
| 12 | 線グラフ | SVG の `polyline`。系列は二本まで |
| 13 | 数値の強調 | 数字 3 つ。結論を一目で渡す |
| 14 | 画像 | 左に説明・右に図版枠（`image-slot`） |
| 15 | コード | 角丸の墨地パネル＋左に説明 |
| 16 | 引用 | 一言だけ。地色をわずかに変える |

足りないレイアウトが出たら、新しく作る前に**内容を削れないか先に検討する**。

## 文字要素の作法

詳細は `reference/tokens.md` の「文字要素」表。要点だけ:

- **見出しは三段。** h1 は表紙と章扉だけ、h2 の直下には必ず 1px の枠罫、h3 に罫線は付けない。四段目が必要ならスライドを割る。
- **ラベル（26px・字間 0.14em・teal）は見出しの階層に入らない。** カラム名や分類名を示す別系統で、h4 の代わりに使う。太字にしない。
- **リストは 5 項目・二階層まで。** 箇条書きは teal の 11px 正方形、第二階層は横罫。番号付きは `01` の二桁ぞろえ＋行間の罫線。
- **インデントは grid の列で作る。** `padding-left` での字下げをしない（折り返しの頭が揃わない）。刻みは 48px、二段まで。段落頭の一字下げは入れない。
- **表は横罫のみ。** 文字列は左、数値は右で `tabular-nums`、単位は見出しへ。5 行 4 列まで。maroon は見せたい差分の 1 列だけ。
- **数式は KaTeX。** `<link>`＋`<script defer>`（CDN）と boilerplate の typeset 関数を残し、式は `data-tex` 属性に書く。独立式は一枚に一つ、上下の枠罫で挟んで右端に式番号。
- **二段組は中央の縦罫線一本で分ける。** 左右の行数を揃える。三段組は作らない。

## 守ること

- **スタイルはすべてインライン。** クラスも CSS 変数も `<style>` ブロックも増やさない（フォント読み込みと body リセットを除く）。レイアウトごとに値を直書きするのが、このテンプレートの設計方針。
- **一枚に主張はひとつ。** 補足は話し手が言う。
- **差し色は maroon と teal の二色だけ。** maroon `#e64553` は主張（一枚に一箇所まで）、teal `#10797a` は構造（番号・記号・カラム見出し）。役割を混ぜない。三色目を作らない。
- **装飾を足さない。** 影・グラデーション・角丸・アイコン・絵文字・左ボーダーの囲みは使わない。階層は文字サイズと余白だけで作る。
- **罫線は二段だけ。** 枠罫 `#8c8fa1`（見出し下・フッター上・表の外側・数式帯）と内部罫 `#bcc0cc`（表・目次の行間・二段組の区切り）。枠罫より濃い線を引かない。`#4c4f69` は線ではなく面の輪郭（図解の箱・写真枠）専用。
- **24px 未満の文字を作らない。**
- 各 `<section>` に `data-label`（サムネイル用の短い名前）と `data-speaker-notes`（読み上げ原稿）を必ず付ける。
- 下端フッターの `PRESENTATION TEMPLATE` は案件名に差し替え、ページ番号は連番で振り直す。不要なら `<div style="margin-top:auto;...">` ごと消す。

## はみ出しの確認

1080px を一枚でも超えるとフッターが画面外に落ちる。**書き終えたら必ず各スライドで `scrollHeight === 1080` を確かめる。**

超えていたら、文字サイズを下げる前に次の順で詰める。

1. 行や項目の上下 `padding`（26px → 14px 程度まで）
2. リード文の `margin-bottom`（44px → 36px）
3. 見出し下の罫線の `margin-bottom`（56px → 44px）
4. それでも収まらなければ**内容を削るか、二枚に割る**

目次・表・行の並びは、項目を増やしたら必ず上下 `padding` を減らす。項目数と余白は連動させる。

## 分量の目安

- 標準レイアウトの項目は 3 つまで。4 つ必要なら表組みに変える。
- 数値スライドは 3 つまで。
- 図解の箱は 4 つまで。箱は角丸 32px・2px 枠、ステップ番号は円で囲む（書体の丸みに合わせる）。角丸は図解の箱とコードパネル（32px）・インラインコード（8px）だけ。表・写真枠・数式帯は角のまま。
- **反転面（`#4c4f69` の地）は「終端」の記号。** 章扉の全面、並びの最終段（図解の 4 段目）、コード・引用の地。この三つ以外に使わない。一枚に一つまで、並びの途中には置かない。重要さは maroon、位置は反転（→ reference/tokens.md）。反転面の番号だけは maroon 淡 `#f2cdcd` の塗り円にして、着地点を一点で示す。
- コードは 12 行まで。超えるなら抜粋する。
- 本文 1 行は全角 30 字程度で折り返す（`max-width` で調整済み）。
- 目次は 5 項目まで。超えるなら章立てを見直す。
- 強調した語句が行末で割れないよう、その段落に `word-break:keep-all` を付ける。

## 図・グラフ

Mermaid や画像生成は使わない。**箱と矢印なら `div` + `border` + grid**（09 図解）、**線でつながる図なら inline SVG**（10 図表・SVG）。**棒グラフは `height` 指定の `div`**（11 棒グラフ）、**折れ線は SVG の `polyline`**（12 線グラフ）。

系列色は `reference/tokens.md` の 6 色を**左から順に**使う。maroon は系列に入れず、異常系にだけ使う。図のなかで到達しない経路・未実行の要素は罫線色 `#8c8fa1` に落とし、maroon の一点に視線を集める。

SVG の作図規則（10 図表・SVG に準拠）:
- `viewBox` で座標を決め、`width:100%;height:auto` で流し込む
- 線は `stroke-width="4"`、`stroke-linecap="round"`、分岐は `C` の三次ベジェ
- 節点は `r="13"`、`fill` は地色 `#eff1f5`、`stroke` に系列色
- 文字は 24〜28px。矢印マーカー・影・グラデーションは付けない
- 凡例は SVG の外に `div` の grid で置く

## 出力後

ブラウザで開くと `deck-stage` がスケーリング・キーボード送り・サムネイル・印刷を引き受ける。
- 矢印キー / スペースで送る
- ブラウザの印刷から PDF（1 スライド 1 ページ）
- サムネイルのドラッグで並べ替え

## 画像

画像は `<img>` を直接書かず、**すべて `<image-slot>` に統一する**（`assets/image-slot.js` を `deck-stage.js` と並べて読む）。枠線は 1px `#4c4f69` を親の `div` に引き、角丸にしない。

- **画像ファイルがあるとき**は `src` に渡す。これが確定した状態。
  `<image-slot id="hero" src="./images/foo.png" shape="rect" fit="contain"></image-slot>`
- **まだ無いとき**は `src` を省き、`placeholder` に何を入れるかを書く。ドラッグで仮置きできる。
- **ドロップした画像はリロードで消える。** 永続化はこのテンプレートの外の仕組みに依存する。決まったら画像を `./images/` に保存し、`src` に書き直して確定させる。
- 顔写真は 420×420 の枠に `fit="cover"`、図版は `fit="contain"`。`shape="rect"`（角丸にしない）。
- `id` はスライドをまたいで重複させない。
- **文字を画像の上に重ねない。**
